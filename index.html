문자 표현 방식: ASCII vs UNICODE

  • 코드의 의미 — ① 프로그래밍 코드 ② 사람의 언어를 기계어로 바꾼 것
  • ASCII — 숫자·영어 1byte / 한글 2byte, 8bit 중 7bit만 데이터 비트로 사용. 예: 'A' = 65, 'a' = 97
  • UNICODE — 전 세계 모든 문자 2byte, 전 세계 문자를 일관되게 표현하기 위해 만들어짐
참고 — 위 바이트 수는 수업 기준입니다. 실제 UTF-8은 문자에 따라 1~4byte 가변 길이입니다. 시험은 수업 기준으로!

순서도 예시 — a부터 b까지의 합

START → 준비(a, b, sum, i = 0) → 입력(READ a, b) → 판단(a > b ?) — True면 tmp로 a, b 교환 → 반복(i=a; i<=b; i++) sum += i → 출력(PRINT sum) → END

#include <stdio.h>

int main(void) {
    int a = 0, b = 0, sum = 0, i = 0;

    printf("두 수를 입력하세요: ");
    scanf("%d %d", &a, &b);

    if (a > b) {          /* 큰 수가 앞이면 교환 */
        int tmp = a;
        a = b;
        b = tmp;
    }
    for (i = a; i <= b; i++) {
        sum += i;
    }
    printf("%d부터 %d까지의 합은 %d입니다.\n", a, b, sum);
    return 0;
}
CHAPTER 02

C 프로그래밍 시작

프로그램 구현 과정

  1. 소스 편집 — C 소스 파일 작성. 하나의 C 프로그램에는 실행 시작점인 main() 함수가 단 한 개만 있어야 한다.
  2. 컴파일 — 소스 코드를 목적 코드로 번역하고 문법 오류 검사
  3. 목적 파일 생성 — 일반적으로 .obj 확장자
  4. 링크 — 링크 에디터가 여러 목적 파일과 라이브러리를 결합
  5. 실행 파일 생성 — 운영체제가 실행할 수 있는 파일 생성
  6. 로드 — 로더 모듈이 실행 파일을 메모리에 적재
  7. 실행 — CPU가 메모리에 적재된 프로그램을 실행

오류(Error) — 프로그램 개발 과정에서 나타나는 모든 문제

시점대표 원인확인 주체

링크 (시간) 오류링커 오류링크 에디터
실행 (시간) 오류논리 오류, 설계 오류실행 환경과 개발자

IDE (Integrated Development Environment, 통합 개발 환경)

  • 편집기, 컴파일러, 디버거 등의 도구를 한 환경에서 사용할 수 있게 제공
  • 예: Visual Studio

전처리와 입출력

전처리

  • 컴파일 전, 전처리기의 전처리 과정이 필요
  • 헤더파일을 불러오는 지시자: #include <헤더파일>
  • 매크로 상수를 정의하는 지시자: #define 이름 값 (예 #define EXCHANGE_RATE 1120.0)

출력 함수 printf()

  • 형태: printf(형식문자열, 출력목록);
  • 형식 지정자: %[flag][width].[precision][type]
요소의미예시 → 결과
flag -좌측 정렬"[%-5d]", 42 → [42   ]
flag +부호 표시"%+d", 42 → +42
flag 0폭이 남으면 0으로 채움"%05d", 42 → 00042
flag #리딩 문자 0, 0x, 0X 포함"%#o %#x", 36, 36 → 044 0x24
width전체 출력 폭"[%5d]", 42 → [   42]
.precision소수점 이하 자릿수"%.3lf", 37.2823 → 37.282
type자료형에 맞는 서식 지정자%d %lf %c %s ...
  • %% — % 문자 자체를 출력 (예: "4.5%%" → 4.5%)
  • %12.3lf — 폭 12, 소수 셋째 자리, 우측 정렬 / %-12.3lf — 좌측 정렬

입력 함수 scanf()

문자 입출력

CHAPTER 05

연산자와 연산식

산술연산자 + − * / %

  • C언어에는 // 연산자가 없다 (정수끼리 /하면 몫만 남음: 7 / 2 == 3)
  • * / %는 + −보다 우선순위가 높다
  • %는 나머지 (7 % 3 == 1)

대입연산자

  • = 오른쪽 결과값을 왼쪽 변수에 저장
  • 축약 대입: += -= *= /= %=

증감연산자

종류동작예 (x = 5)
전위 ++x, --x값을 증감한 이후 연산y = ++x; → x=6, y=6
후위 x++, x--연산한 이후 값을 증감y = x++; → x=6, y=5
주의 — 상수에는 사용 불가 (++300), 일반 수식에는 사용 불가 ((a+1)--)

관계·논리 연산자

  • 대소비교 < > <= >= / 동등비교 == !=
  • 논리 &&(AND), ||(OR), !(NOT)

형변환

  • 올림변환 — 작은 범주 → 큰 범주 자료형
  • 내림변환 — 큰 범주 → 작은 범주. 범위 밖 데이터는 버려짐 (float 3.14 → int 3)
  • 명시적 형변환 — (int)a 처럼 자료형을 직접 명시
  • 묵시적 형변환 — 컴파일러가 자동 수행
실수 연산 팁 — 4/3은 정수 나눗셈이라 1이 된다. 실수 결과가 필요하면 4.0/3.0처럼 쓴다 (연습문제 5.4, 6.10).

연산 순서

증감(전위), 형변환 → 산술 → 관계 → 논리 → 삼항 → 대입 → 증감(후위)

수학 함수 (#include <math.h>)

  • pow(a, b) = ab, sqrt(x) = √x
  • 복리: 원금 × (1 + 이율)년 → principal * pow(1 + rate, years)
CHAPTER 06

조건

조건문: 두 개 또는 여러 개 중 하나를 선택하는 구조.

if 문

  • 조건이 참이면 if의 코드를 실행
  • if–else if–else 묶음은 위에서부터 검사하여 처음 참이 된 조건의 블록만 실행. 모두 거짓이면 else 실행
  • else는 필수가 아니다
if (조건1) {
    실행할 코드1
} else if (조건2) {
    실행할 코드2
} else {
    실행할 코드3
}

switch 문

  • 식의 결과에 따라 코드를 실행
  • 식의 결과와 case 값은 정수 또는 문자형 상수여야 한다
  • break가 없으면 해당 case 이후의 모든 코드가 실행된다 (fall-through)
  • default는 해당 case가 없을 때 실행. 생략 가능하며 위치 제한 없음
switch (식) {
    case 값1:
        실행할 코드1
        break;
    case 값2:
        실행할 코드2
        break;
    default:
        실행할 코드3
}

조건연산자 (삼항연산자)

조건 ? 참일 때 값 : 거짓일 때 값 — 예: max = (a > b) ? a : b;

자주 나오는 조건식

  • 윤년: (year % 4 == 0 && year % 100 != 0) || year % 400 == 0
  • 짝수: n % 2 == 0 / 배수: n % k == 0
CHAPTER 07

반복

반복문: 반복 몸체인 여러 문장을 여러 번 반복하는 구조.

반복문특징형태
for제어변수의 초기화와 증감을 이용. 초기값·조건·증감은 생략도, 2개 이상도 가능. 조건을 콤마로 연결하면 가장 오른쪽 식이 참일 때 반복for (초기값; 조건; 증감) { ... }
while실행 전에 조건 검사 → 0번 실행될 수도 있음while (조건) { ... }
do while한 번 실행 후 조건 검사 → 최소 1번 실행do { ... } while (조건);

분기문 — 정해진 장소로 이동하는 구조

  • break — 반복 중단. 중첩 반복문에서는 가장 가까운 반복만 중단
  • continue — 이후 반복 몸체의 나머지를 건너뛰고 다음 반복 계속
  • return — 함수 실행을 즉시 종료하고 호출한 곳으로 값을 돌려줌

중첩 반복 패턴 — 소수 판별

for (int i = 2; i <= 100; i++) {
    int is_prime = 1;
    for (int j = 2; j < i; j++) {
        if (i % j == 0) { is_prime = 0; break; }   /* 나누어 떨어지면 소수 아님 */
    }
    if (is_prime) printf("%d ", i);
}

  • 마름모=판단, 평행사변형=입출력, 육각형=준비

02 C 시작

  • 편집→컴파일→.obj→링크→실행파일→로드→실행
  • main()은 단 한 개
  • 문법 오류=컴파일러 / 링커 오류=링크 에디터 / 논리 오류=실행 시
  • IDE = 편집기+컴파일러+디버거 (Visual Studio)

03 자료형·변수

  • %d int · %ld long · %lld long long · %u unsigned
  • %f float · double은 입력 %lf
  • %c 문자 · %s 문자열 · %o 8진 · %x 16진 · %e 지수
  • 021(8진)=17, 0x1b(16진)=27
  • 2의 보수 = 1의 보수 + 1
  • k bit: 2의 보수 −2k−1~2k−1−1, unsigned 0~2k−1

04 전처리·입출력

  • #include 헤더 / #define 매크로 상수
  • %[flag][width].[precision][type]
  • flag: − 좌측, + 부호, 0 0채움, # 0/0x 붙임
  • %% → % 출력
  • scanf는 변수 앞에 &
  • getchar / putchar 문자 1개 입출력

05 연산자

  • C에 // 없음, 정수/정수 = 몫
  • ++x 먼저 증가, x++ 나중 증가
  • 상수·수식엔 ++/−− 불가
  • 내림변환 시 데이터 손실 (3.14→3)
  • 순서: 전위·형변환→산술→관계→논리→삼항→대입→후위
  • pow, sqrt → math.h

06 조건

  • if–else if–else: 처음 참인 블록 하나만
  • else, default는 생략 가능
  • switch case는 정수·문자 상수만
  • break 없으면 아래 case 계속 실행
  • 삼항: 조건 ? 참 : 거짓
  • 윤년: 4의 배수 && 100의 배수 X, 또는 400의 배수

07 반복

  • for: 초기·조건·증감 생략/여러 개 가능
  • while: 먼저 검사 (0회 가능)
  • do while: 최소 1회, 끝에 세미콜론
  • break: 가장 가까운 반복 탈출
  • continue: 나머지 건너뛰고 다음 반복
  • return: 함수 종료 + 값 반환
